# Marine Monitoring & Sensors

**Last Updated**: 2026-06-01  
**Companies Tracked**: 12

This sector covers companies building coral reef monitoring, autonomous surface vessels (ASVs), autonomous underwater vehicles (AUVs), underwater imaging systems, fiber optic sensing, and other marine sensor platforms. These companies provide the observational infrastructure that enables data-driven ocean management, conservation, and scientific research.

## Cross-Company Marine Data Patterns
- **Autonomous platforms**: All companies build autonomous systems (ASVs, AUVs, cameras) for persistent ocean monitoring
- **Survey-grade data**: High-resolution oceanographic and environmental data collection from autonomous platforms
- **Cost reduction**: Common theme of reducing marine data collection costs through automation (Omission 50-70%, MarineSitu >4000 days durability, Ocean State Sensing 800m+ range)
- **Conservation focus**: BeamSea targets coral reef health; HALOBLUE targets coastal restoration; others serve broader ocean observation needs
- **Hardware + data**: All combine physical monitoring platforms with data delivery (cloud dashboards, processed datasets, AI analysis)
- **Underwater imaging**: MarineSitu, Seeweed, and Sunfish all address the underwater imaging gap — species detection, biodiversity mapping, long-term monitoring
- **Fiber optic sensing**: Ocean State Sensing's DTS approach provides unprecedented water column temperature resolution (25cm intervals)
- **Edge AI**: MarineSitu's SituAI processes >95% classification accuracy onboard, reducing data transmission costs
- **Portability**: Sunfish's person-portable AUV and HALOBLUE's lower-cost approach both democratize access to underwater monitoring

## Data & Measurement Needs
Marine monitoring companies need:
- Oceanographic sensor data (temperature, salinity, dissolved oxygen, pH)
- Bathymetric and seafloor mapping data
- Underwater acoustic data
- Water quality station network data
- Satellite remote sensing validation data (SST, chlorophyll, sea surface height)
- Coastal baseline survey data
- Species reference databases for AI classification
- Habitat classification reference data
- Long-term biodiversity monitoring baselines
