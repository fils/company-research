# Zeaclub

**Sector**: Maritime Operations & Analytics
**Official Site**: https://www.zeaclub.com/

## Overview
Zeaclub brings every maritime stakeholder — shipowners, charterers, brokers, agents — and every document and decision into one AI-powered shared workspace. Eliminates email chains, spreadsheet ping-pong, and costly data entry errors across the shipping value chain.

## Business Model
- **Product:** AI-powered collaborative workspace (SaaS) for maritime operations
- **Markets:** Shipowners, charterers, brokers, operators, finance teams in maritime shipping
- **Stage:** Early access / pre-launch
- **Funding:** VentureWell/NOAA OEA Stage 0 (Spring 2026)

## Key Technology
- AI-powered structured data workspace for voyage management
- Role-based permissions with full audit trail
- Automated laytime calculations, freight invoices, demurrage claims
- Secure encrypted platform with isolated voyage workspaces

### Data & Measurement Needs
- **Primary data types:** Voyage data, charter terms, port schedules, cost data, vessel specifications, demurrage/despatch data
- **Key measurements/parameters:** Laytime, freight rates, fuel consumption, port turnaround times, vessel performance metrics
- **Observation platforms:** Platform itself — user-input structured data; potential integration with AIS, port APIs
- **Known data gaps:** Integrated real-time vessel tracking; standardized maritime data exchange formats across the industry
- **Interest in external data services:** AIS data integration, port schedule APIs, weather routing data, vessel registry databases
