# BeamSea Associates – Raw Web Extract
**Source:** VentureWell OEA Spring 2026 Stage 1 Cohort

## Business Model
BeamSea Associates automates coral reef ecosystem monitoring at operationally relevant scales using fluorescence-enhanced, high-resolution 3D LiDAR + machine learning. Species-level assessment for reef health.

### Technology
- Fluorescence-enhanced 3D LiDAR imaging system for underwater biological substrates
- Machine learning for species-level coral reef classification
- "Underwater Multispectral Laser Serial Imager" for spectral discrimination of benthic organisms
- Elastic and inelastic LiDAR pulse return phenomenology in coastal substrates
