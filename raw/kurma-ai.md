# Kurma AI – Raw Web Extract
**Source:** https://kurma.ai/

## Overview
Kurma AI (San Francisco, CA) builds domain-specific AI for aquaculture and fisheries. Their mission is to make aquaculture efficient, sustainable, and resilient through generative AI, computer vision, and intelligent automation.

## Selected Programs
- VentureWell/NOAA Ocean Enterprise Accelerator Stage 0 (Spring 2026)
- NVIDIA Inception program
- Nebius partnership
- Google for Startups Cloud Program (joined August 2025)

## Products
1. **AQUA Models** – Domain-specific foundational language models for aquaculture (AQUA-7B on Hugging Face)
2. **AquaChat** – World's first free AI assistant for aquaculture farmers. Voice-enabled in 13+ languages. Available on Web, iOS, and Android.
3. **AQUA OS** – Agentic AI platform for autonomous aquaculture operations. Real-time pond/farm monitoring dashboard showing pH, temperature, dissolved oxygen, NH₃ levels, device control (aerator, feeder, pump, filter, drain valve), camera feeds, sensor status, and agent activity logging.
4. **AquaEye** – Computer vision system for fisheries security, compliance, and monitoring.

## Key Measurements Handled
- pH, temperature, dissolved oxygen (DO), NH₃ (ammonia)
- Real-time sensor telemetry from aquaculture ponds
- Camera-based fish behavior analysis for health monitoring
- Feed optimization via AI-driven consumption analysis

## Business Model
SaaS platform: AI model access, mobile app, agentic OS platform, and compliance computer vision. Partnerships with NVIDIA, Google, and Nebius for compute infrastructure.

## Data Needs
- Real-time water quality data (pH, DO, temperature, NH₃, salinity)
- Underwater camera feeds for fish health/behavior monitoring
- Large aquaculture operational datasets for model training
- Multi-lingual aquaculture knowledge base (13+ languages)
